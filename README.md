# Reproov Station

Application de bureau des réparateurs partenaires Reproov : elle lit les appareils branchés au comptoir
(Android en USB, iPhone, Bluetooth) et envoie les résultats au banc de test.

Ce dépôt ne contient que les installateurs. Téléchargez la dernière version :

- Mac (puce Apple) : [Reproov-Station-mac-arm64.dmg](https://github.com/pj875/reproov-station/releases/latest/download/Reproov-Station-mac-arm64.dmg)
- Mac (Intel) : [Reproov-Station-mac-x64.dmg](https://github.com/pj875/reproov-station/releases/latest/download/Reproov-Station-mac-x64.dmg)
- Windows : [Reproov-Station-win-x64.exe](https://github.com/pj875/reproov-station/releases/latest/download/Reproov-Station-win-x64.exe)

Après l'installation, ouvrez la Station : elle affiche un code à 6 chiffres à saisir dans l'espace partenaire,
Paramètres → « Reproov Station ».
